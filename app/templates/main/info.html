StudentSpot to lekka aplikacja webowa dla społeczności akademickiej: łączy katalog kół naukowych, rezerwację sal przy Sterlinga 26, role administracyjne, powiadomienia i dostępność cyfrową w jednym systemie.

StudentSpot is a lightweight web application for the academic community: it combines a student club catalog, Sterlinga 26 room booking, admin roles, notifications, and digital accessibility in one system.

StudentSpot is not an official AHE system. Club and room data comes from public university sources and is labeled with a verification status.

{% if locale == "pl" %}

Wygląd aplikacji został dopasowany do key visual AHE, ponieważ zależało mi na tym, aby prototyp estetycznie pasował do komunikacji uczelni. Podstawą były materiały znalezione w kodzie strony www AHE (tryb inspect/dev z przeglądarki Chrome), źródło: view-source:https://www.ahe.lodz.pl//themes/custom/ahe/css/style.css.

Na tej podstawie interfejs używa palety AHE: czerwieni #A91539, granatu #222A56, prostych prostokątnych paneli, jasnoszarych powierzchni oraz typografii opartej o stack Mundial / Neue Haas Grotesk / Arial. Zachowałem też tryb ciemny, wysoki kontrast i większą czcionkę dla dostępności.

{% else %}

The interface was adapted to the AHE key visual because I wanted the prototype to visually match the university communication. The basis was material found in the AHE website code using Chrome inspect/dev tools, source: view-source:https://www.ahe.lodz.pl//themes/custom/ahe/css/style.css.

The UI therefore uses the AHE palette: red #A91539, navy #222A56, rectangular panels, light gray surfaces, and a Mundial / Neue Haas Grotesk / Arial font stack. Dark mode, high contrast, and larger text remain available for accessibility.

{% endif %}
